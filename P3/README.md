# Weather - заготовка P3

Стрічка P2, перенесена у файли маршрутів, і навігація, з'єднана лише наполовину.
React Native + **Expo SDK 57**, TypeScript, expo-router.
**Цей файл і є завдання** - специфікація, критерії та бали нижче.

Заготовка запускається в Expo Go і одразу показує живий старт: три таби знизу,
стрічка трьохсот міст на першому. Але глибша навігація ще не з'єднана: коренева
розкладка не оголошує екран міста, тап по картці нічого не відкриває, а сам
екран міста ігнорує адресу. Стрічка P2 лежить у `app/(tabs)/index.tsx` без
змін. Ваша робота - чотири TODO, і всі чотири про навігацію.

## Як працювати

Кожен TODO живе в одному файлі, і поруч лежить **закоментований каркас** -
розкоментуйте, адаптуйте і доповніть своїм. Каркас дає механіку навігації;
**верстка екрана міста - ваша власна робота**.
Після кожного кроку застосунок лишається робочим - одразу видно у Expo Go,
що саме змінилося.

## Завдання

З'єднати навігацію: корінь-`Stack`, три таби і екран міста за параметром.

| # | Що зробити | Де |
|---|---|---|
| 1 | Оголосити екран міста в кореневій розкладці; заголовок (tabs) уже стоїть, заголовок міста - динамічний, із самого екрана | `app/_layout.tsx` |
| 2 | Іконки трьом табам: `tabBarIcon` з Ionicons ('list', 'search', 'map'); заголовки вже стоять | `app/(tabs)/_layout.tsx` |

| 4 | Тап по картці відкриває екран цього міста через `push` | `app/(tabs)/index.tsx` |

Робіть за порядком: номер і є порядок.

## Як запустити

Потрібні **Node.js LTS** на ноутбуці та **Expo Go** на телефоні (App Store / Google Play).

```bash
npm install
npx expo start          # QR-код у терміналі
```

Відскануйте QR-код камерою (iOS) або застосунком Expo Go (Android). Ноутбук і
телефон у різних Wi-Fi мережах: `npx expo start --tunnel`.

## «Зроблено» виглядає так

Три таби знизу, стрічка на першому, екран міста поверх усього - без таб-бару,
з поверненням на ту саму позицію скролу. Точна картина і кроки самоперевірки -
у завданні.
